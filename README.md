# TODO Scheduler

## Описание проекта
Это веб-приложение-планировщик задач (TODO Scheduler), написанное на Go 
Приложение позволяет:  
- Создавать, редактировать и удалять задачи  
- Отмечать задачи как выполненные  
- Просматривать список задач  

Фронтенд доступен в директории `web`.

---

## Список выполненных заданий со звёздочкой
- Реализована аутентификация через пароль с использованием JWT  
  - `/api/task`
  - `/api/tasks`
  - `/api/task/done`
  - вроде ничего не забыл

## Локальный запуск

1. Установите пароль (для Git Bash):

```bash
export TODO_PASSWORD=12345

2. Установите порт и путь к базе данных:

export TODO_PORT=7540
export TODO_DBFILE=/path/to/todo.db


3. Запустите сервер:

go run main.go


4. Откройте фронтенд в браузере:

http://localhost:7540/login.html
